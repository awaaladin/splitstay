If it doesn't install

Your phone is only being careful.

SplitPay isn't on the Play Store yet, so Android and Chrome ask you to confirm. Find the message you see.

Chrome says the file might be harmful{% icon "chevron-down" 18 %}

Chrome shows this for any app from outside the Play Store. Tap Download anyway. If you don't see it, open Chrome's menu (the three dots), tap Downloads, and look for SplitPay.apk.

It says it can't install apps from this source{% icon "chevron-down" 18 %}

Open Settings, then Apps, then Chrome (tap See all apps if it isn't listed). Tap Install unknown apps and turn on Allow from this source. Go back and tap SplitPay.apk again. Wording differs a little between phone brands, so search Settings for "unknown apps" if you can't find it. You can turn it off after installing.

Google Play Protect shows a warning{% icon "chevron-down" 18 %}

Tap More details, then Install anyway.

The download doesn't start{% icon "chevron-down" 18 %}

Check your connection and that you have a little free space, then try again. If it still won't start, open Chrome's menu, then Settings, Site settings and Automatic downloads, and allow it.

It says the app wasn't installed when updating{% icon "chevron-down" 18 %}

Uninstall the old SplitPay app, then install the new one. Your groups and payments are stored in your account, so nothing is lost. You'll just sign in again.
